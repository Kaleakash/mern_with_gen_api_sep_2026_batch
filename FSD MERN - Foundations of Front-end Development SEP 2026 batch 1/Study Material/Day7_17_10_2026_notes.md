2. Types of functions in JavaScript
The following are important function types to learn.

Type	Description
1. Function declaration	A function declared using the function keyword
2. Function with parameters	Accepts input values
3. Function with return value	Returns a result to the caller
4. Function expression	Stores a function in a variable
5. Anonymous function	A function without a name
6. Arrow function	Uses the => syntax
7. Callback function	A function passed to another function

4. Function with parameters
Parameters allow a function to accept input values.
Example: Calculate employee salary
<script>
    function calculateSalary(basicSalary, bonus) {
        let totalSalary = basicSalary + bonus;

        document.write("Basic Salary: ₹" + basicSalary + "<br>");
        document.write("Bonus: ₹" + bonus + "<br>");
        document.write("Total Salary: ₹" + totalSalary + "<br>");
    }

    calculateSalary(30000, 5000);
    document.write("<hr>");
    calculateSalary(40000, 8000);
</script>


Output:
Basic Salary: ₹30000
Bonus: ₹5000
Total Salary: ₹35000

Basic Salary: ₹40000
Bonus: ₹8000
Total Salary: ₹48000

Explanation:
- basicSalary and bonus are parameters.
- 30000 and 5000 are arguments in the first function call.
- The function uses these values to calculate the total salary.
5. Function with a return value
The return statement sends a result back to the code that called the function.
<script>
    function calculateTotal(price, quantity) {
        let total = price * quantity;
        return total;
    }

    let bill = calculateTotal(500, 4);

    document.write("Total Bill: ₹" + bill);
</script>


Output:
Total Bill: ₹2000


How it works:
1. The function receives 500 and 4.
2. It calculates 500 * 4.
3. return total sends 2000 back.
4. The result is stored in the bill variable.
Important: return and document.write() are different. return gives a value back to the caller; document.write() displays content on the page.
6. Function expression
A function expression stores a function in a variable.
const calculateArea = function(length, width) {
    return length * width;
};

let area = calculateArea(10, 5);

document.write("Area of Rectangle: " + area);


Output:
Area of Rectangle: 50


Here, calculateArea is a variable holding a function. Because it is declared with const, the variable cannot be reassigned.
7. Anonymous function
An anonymous function is a function without its own name. It is commonly used as a callback or assigned to a variable.
const showMessage = function() {
    document.write("Your registration is successful!");
};

showMessage();


Output:
Your registration is successful!


The function itself has no name after the function keyword, but the variable showMessage provides a way to call it.
8. Arrow function
An arrow function provides a shorter syntax for writing functions.
Traditional function
function add(a, b) {
    return a + b;
}

document.write(add(10, 20));


Equivalent arrow function
const add = (a, b) => {
    return a + b;
};

document.write(add(10, 20));


Output:
30


Shorter arrow function
When the function contains only a single return expression, you can omit the braces and return keyword.
const add = (a, b) => a + b;

document.write("Addition: " + add(10, 20));


Output:
Addition: 30


Arrow functions are widely used in modern JavaScript, React, array methods, and asynchronous programming.
9. Callback function
A callback is a function passed as an argument to another function. The receiving function can execute it when needed.
Example: Employee notification

}

function sendNotification() {
    document.write("Employee registration completed!");
}

Output:
Processing employee: Rahul
Employee registration completed!


Notice that we pass sendNotification without parentheses. The receiving function calls it using callback().

Function Declaration vs Function Expression vs Arrow Function

Feature: Syntax
Function Declaration: function add() {}
Function Expression: const add = function() {}
Arrow Function: const add = () => {}

Feature: Name
Function Declaration: Usually named
Function Expression: Named or anonymous
Arrow Function: Often stored in a variable

Feature: Hoisting
Function Declaration: Entire function is hoisted
Function Expression: Depends on variable declaration
Arrow Function: Depends on variable declaration

Feature: Own this
Function Declaration: Yes; depends on how the function is called
Function Expression: Yes; depends on how the function is called
Arrow Function: No; inherits this from the surrounding scope

Feature: Common Use
Function Declaration: General-purpose functions
Function Expression: Assigned functions and callbacks
Arrow Function: Modern JavaScript, callbacks, and React


Important Notes:

1. Function declarations can be called before their declaration because the entire function is hoisted.

2. Function expressions assigned to let or const cannot be called before the variable is initialized.

3. Arrow functions assigned to let or const cannot be called before the variable is initialized.

4. Arrow functions do not have their own this; they inherit it from the surrounding scope.

JavaScript Events and Event Listeners
In JavaScript, events allow a web page to respond to user actions, such as clicking a button, typing in a text box, submitting a form, or moving the mouse.
1. What is an Event?
An event is an action or occurrence detected by the browser that JavaScript can respond to.
Examples:
- A user clicks a button.
- A user enters text into an input field.
- A user submits a login form.
- A web page finishes loading.
- A user moves the mouse over an element.
Real-time example: When a user clicks the Login button, JavaScript validates the entered credentials and displays a message.
2. Types of JavaScript Events
Event	Meaning	Example use case
click	User clicks an element	Login button
dblclick	User double-clicks an element	Open an item
mouseover	Mouse moves over an element	Highlight a menu
mouseout	Mouse leaves an element	Remove highlighting
keydown	User presses a keyboard key	Keyboard shortcuts
keyup	User releases a key	Detect keyboard input
input	Input value changes	Live search
change	Input value is committed or selection changes	Select department
submit	User submits a form	Login or registration
focus	An element receives focus	Highlight a text field
blur	An element loses focus	Validate a field
load	A resource finishes loading	Initialize a page
DOMContentLoaded	HTML has been parsed	Initialize JavaScript
3. What is an Event Listener?
An event listener is a function registered to execute when a specified event occurs on an element.
For example:
button.addEventListener("click", function () {
    alert("Button clicked!");
});


Meaning:
- button — the HTML element being monitored.
- addEventListener() — registers the event listener.
- "click" — the event to listen for.
- function() — the code executed when the event occurs.
4. Registering Events on the HTML Side
HTML event registration means writing an event attribute directly inside an HTML element.
Example: HTML onclick
Save this as html-event.html and open it in your browser.

<!DOCTYPE html>
<html>
<head>
    <title>HTML Event Example</title>
</head>
<body>
    <h2>Employee Management</h2>

    <button onclick="showMessage()">
        Save Employee
    </button>

    <script>
        function showMessage() {
            alert("Employee saved successfully!");
        }
    </script>
</body>
</html>
  



How it works:
1. The browser displays the Save Employee button.
2. The user clicks the button.
3. The onclick event attribute calls showMessage().
4. JavaScript displays an alert.
Here, the event is registered directly in HTML using onclick.
Other HTML event attributes include onchange, oninput, onsubmit, and onmouseover.
5. Registering Events on the JavaScript Side
JavaScript event registration means selecting an HTML element and attaching a listener using addEventListener().
Example: JavaScript addEventListener()
Save this as javascript-event.html and open it in your browser.

<!DOCTYPE html>
<html>
<head>
    <title>JavaScript Event Example</title>
</head>
<body>
    <h2>Employee Management</h2>

    <button id="saveBtn">
        Save Employee
    </button>

    <script>
        const button = document.getElementById("saveBtn");

        button.addEventListener("click", function () {
            alert("Employee saved successfully!");
        });
    </script>
</body>
</html>
  



How it works:
1. getElementById("saveBtn") selects the button.
2. addEventListener("click", ...) registers a click listener.
3. When the user clicks the button, the callback function executes.
4. The browser displays the alert.
This approach is generally preferred for modern JavaScript because it separates HTML structure from JavaScript behavior and allows multiple listeners for the same event.
6. HTML Registration vs JavaScript Registration
Feature	HTML-side registration	JavaScript-side registration
Syntax	onclick="save()"	addEventListener("click", save)
Where registered	Inside the HTML element	Inside JavaScript
Separation of concerns	HTML and behavior are mixed	HTML and behavior are separated
Multiple listeners	Inline handler property supports one assigned handler	Multiple listeners can be registered
Recommended use	Simple demonstrations or legacy code	Modern applications

B. Constructor function
A constructor function allows us to create multiple objects with the same structure.
function Employee(id, name, department) {
    this.id = id;
    this.name = name;
    this.department = department;
}

const e1 = new Employee(101, "Akash", "IT");
const e2 = new Employee(102, "Priya", "HR");

console.log(e1.name);        // Akash
console.log(e2.department);  // HR


C. Class
A class provides a structured way to define objects.
class Student {
    constructor(id, name) {
        this.id = id;
        this.name = name;
    }

    display() {
        console.log(this.id + " - " + this.name);
    }
}

const s1 = new Student(1, "Rahul");
s1.display(); // 1 - Rahul
