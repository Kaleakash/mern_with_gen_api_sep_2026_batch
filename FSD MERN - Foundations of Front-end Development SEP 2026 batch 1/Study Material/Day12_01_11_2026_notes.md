What is CSS?
CSS stands for Cascading Style Sheets. It is used to style HTML 
elements and control the presentation of web pages.

For example, consider this HTML:
<h1>Welcome to Online Food App!</h1>


Using normal CSS:
h1 {
    color: red;
    background-color: yellow;
    text-align: center;
    padding: 20px;
}


Problem with traditional CSS:
- We need to write separate CSS rules.
- We need to create and maintain CSS classes.
- Large projects may have many CSS files.
- Responsive design requires additional CSS rules.
To simplify styling, developers commonly 
use CSS frameworks such as Bootstrap and Tailwind CSS.


What is Bootstrap?

Bootstrap is a popular frontend CSS framework used to 
develop responsive and mobile-first websites quickly.

It provides predefined:
- Buttons
- Cards
- Navigation bars
- Forms
- Modals
- Alerts
- Dropdowns
- Grid systems
- Tables
- Responsive utilities

Instead of writing CSS from scratch, developers use predefined Bootstrap classes.
Example: Normal CSS vs Bootstrap

Normal CSS:


<input type>




<button class="my-button">Submit</button>

.my-button {
    background-color: blue;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 5px;
}

Bootstrap:
<button class="btn">
    Submit
</button>
<button class="btn btn-success">
    Submit
</button>
<button class="btn btn-info">
    Submit
</button>
<button class="btn btn-primary">
    Submit
</button>

Here:
- btn defines the button styling.
- btn-primary defines the primary button color.
You don't need to write separate CSS for this button.

3. Bootstrap installation and setup
There are two common ways to use Bootstrap.
Method 1: Using CDN (No installation required)
Add Bootstrap CSS and JavaScript CDN links to your HTML.

<!DOCTYPE html>
<html>
<head>
    <title>Bootstrap Demo</title>

    <!-- Bootstrap CSS -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
          rel="stylesheet">
</head>
<body>

    <div class="container mt-5">
        <h2 class="text-primary">Welcome to Bootstrap</h2>

        <button class="btn btn-success">
            Click Me
        </button>
    </div>

    <!-- Bootstrap JavaScript -->
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>

</body>
</html>



Advantages:
- No installation.
- Easy for beginners.
- Useful for small projects and demonstrations.
- Requires internet connectivity.

Bootstrap grid system
Bootstrap provides a 12-column grid system to create responsive layouts.

Important classes:
Class	            Purpose
container	        Fixed responsive-width container
container-fluid	    Full-width container
row	                Creates a horizontal row
col	                Automatically distributes columns
col-6	            Takes 6 of 12 columns
col-4	            Takes 4 of 12 columns
col-3	            Takes 3 of 12 columns
col-md-6	    Six columns on medium screens and larger

Example: Three-column layout

<div class="container">
    <div class="row">

        <div class="col-md-4">
            <h3>Java</h3>
        </div>

        <div class="col-md-4">
            <h3>Python</h3>
        </div>

        <div class="col-md-4">
            <h3>React</h3>
        </div>

    </div>
</div>


Explanation:
- container creates the main content area.
- row creates the grid row.
- col-md-4 gives each column 4 out of 12 grid units on medium and larger screens.
- On smaller screens, these columns stack vertically by default.

What is Tailwind CSS?

Tailwind CSS is a utility-first CSS framework used to design responsive and modern web applications directly inside HTML using predefined utility classes.

Unlike Bootstrap, Tailwind does not primarily provide ready-made components such as cards and buttons.

Instead, it provides small utility classes that control individual CSS properties.
Example: Normal CSS vs Tailwind

Normal CSS:

<h1 class="heading">Welcome to Food App</h1>

.heading {
    color: blue;
    font-size: 30px;
    font-weight: bold;
    text-align: center;
    margin-top: 20px;
}


Tailwind CSS:

<h1 class="text-blue-600 text-3xl font-bold text-center mt-5">
    Welcome to Food App
</h1>


Explanation:
Tailwind class	        CSS equivalent
text-blue-600	        Text color
text-3xl	            Font size
font-bold	            Font weight
text-center	            Text alignment
mt-5	                Margin top

The important concept is that you combine multiple utility classes to achieve the required design.
8. Tailwind CSS installation and setup
There are two common approaches.
Method 1: CDN for learning and quick demonstrations
For a simple HTML practical, you can use the browser CDN.

<!DOCTYPE html>
<html>
<head>
    <title>Tailwind Demo</title>

    <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
</head>
<body>

    <div class="p-5 bg-blue-600 text-white text-center">
        <h1 class="text-3xl font-bold">
            Welcome to Tailwind CSS
        </h1>
    </div>

</body>
</html>



Advantages:
- No npm installation.
- No build configuration.
- Useful for learning and experimentation.
Important: The browser CDN is intended for development and learning, not production deployment.

CSS vs Bootstrap vs Tailwind CSS
CSS, Bootstrap and Tailwind CSS are all used to design and style web pages. However, they work differently.

The easiest way to understand them is:
- CSS: Write your own styling rules.
- Bootstrap: Use predefined CSS classes and ready-made components.
- Tailwind CSS: Combine small utility classes directly in HTML to create your own designs.

Major differences
Feature	                CSS	                        Bootstrap	                    Tailwind CSS
Type	                Styling language	        Component-based framework	    Utility-first framework
Styling	Write           CSS yourself	            Predefined classes	            Utility classes
Ready-made components	No	                        Yes	                            Not built in
Customization	        Complete control	        Customizable	                Complete control
HTML classes	        Custom classes	            Bootstrap classes	            Utility classes
Learning	            CSS fundamentals needed	    Easy to start	                Learn utility classes
