
Margin Properties

margin creates space outside an element.

        Margin
   ┌─────────────────┐
   │     Border      │
   │  ┌───────────┐  │
   │  │  Content  │  │
   │  └───────────┘  │
   └─────────────────┘

   | Property        | Purpose   |
| --------------- | --------- |
| `margin`        | All sides |
| `margin-top`    | Top       |
| `margin-right`  | Right     |
| `margin-bottom` | Bottom    |
| `margin-left`   | Left      |


Example
.employee-card {
    margin: 20px;
}

Individual sides:

.employee-card {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 30px;
    margin-left: 20px;
}

Padding Properties

padding creates space inside an element, between content and border.

┌──────────────────────────────┐
│          Padding             │
│   ┌──────────────────────┐   │
│   │       Content        │   │
│   └──────────────────────┘   │
│          Padding             │
└──────────────────────────────┘

| Property         | Purpose   |
| ---------------- | --------- |
| `padding`        | All sides |
| `padding-top`    | Top       |
| `padding-right`  | Right     |
| `padding-bottom` | Bottom    |
| `padding-left`   | Left      |


Example
.employee-card {
    padding: 20px;
}

A very common UI combination:

.employee-card {
    margin: 20px;
    padding: 20px;
    border: 1px solid #7b1f1f;
}

Remember:

Margin = outside space
Padding = inside space

7. Width and Height

Used to control the dimensions of an element.

| Property     | Purpose        |

| `height`     | Height         |
| `min-width`  | Minimum width  |

| `min-height` | Minimum height |
| `max-height` | Maximum height |


Example
.employee-card {
    width: 300px;
    min-height: 200px;

Responsive example:

.employee-card {
    width: 100%;

This is often better than:

.employee-card {
    width: 400px;

because the max-width version can adapt to smaller screens.

10. Flexbox Properties

Flexbox is one of the most important CSS layout systems.

Container properties

| Property          | Purpose                |
| ----------------- | ---------------------- |
| `display: flex`   | Creates flex container |
| `flex-direction`  | Row/column             |

| `align-items`     | Cross-axis alignment   |

Important Flexbox properties

display: flex;

Makes the element a Flex Container.

flex-direction: row;

Arranges children horizontally.

flex-direction: column;

Arranges children vertically.

        │                     │

Box Model

Controls one element's space:

       margin
          ↓
    ┌─────────────┐
    │   border    │
    │ ┌─────────┐ │
    │ │padding  │ │
    │ │ content │ │
    │ └─────────┘ │
    └─────────────┘
Flexbox

Controls how multiple elements are arranged:

┌───────────────────────────────────────────────┐
│ Product      Price       Quantity      Action │
│   ↓           ↓             ↓            ↓    │
└───────────────────────────────────────────────┘
                 FLEXBOX
Easy way to remember

Box Model = Space of an element

Flexbox = Arrangement of elements

And in real applications, they are normally used together.

For example, in an Amazon-style application:

Shopping Cart
     │
     ├── Flexbox → arrange Product, Price, Quantity, Button
     │
     └── Box Model → control padding, border, margin and size
                     of each cart item

This is a much more realistic example because 
Box Model handles the individual component's physical space, 
while Flex-box handles the layout of its internal components.

JavaScript: var vs let vs const

1. What are var, let, and const?
In JavaScript, var, let, and const are keywords used to 
declare variables. A variable stores data such as employee names, salaries, marks, and status.
Example:
var employeeName = "Rahul";
let employeeAge = 25;
const companyName = "ABC Technologies";

document.write("Employee Name: " + employeeName + "<br>");
document.write("Employee Age: " + employeeAge + "<br>");
document.write("Company Name: " + companyName);


Output in the browser:
Employee Name: Rahul
Employee Age: 25
Company Name: ABC Technologies

2. Difference between var, let, and const
Feature	var	let	const
Scope	Function-scoped	Block-scoped	Block-scoped
Redeclaration in same scope	Allowed	Not allowed	Not allowed
Reassignment	Allowed	Allowed	Not allowed
Must initialize at declaration?	No	No	Yes
Hoisting	Yes; initialized as undefined	Yes; inaccessible before declaration	Yes; inaccessible before declaration
Recommended usage	Legacy code	Values that change	Bindings that should not be reassigned
Remember:
- Use let when the variable's value needs to change.
- Use const when the variable should not be reassigned.
- Avoid var in most modern JavaScript code because its 
function-scoped behavior can cause unexpected results.

3. Example 1: var — Variable can be reassigned
Real-time example: An employee's salary changes after a bonus.
<!DOCTYPE html>
<html>
<body>
    <h2>var Example</h2>

    <script>
        var salary = 40000;

        document.write("Initial Salary: ₹" + salary + "<br>");

        salary = 45000;

        document.write("Updated Salary: ₹" + salary);
    </script>
</body>
</html>


Output:
var Example
Initial Salary: ₹40000
Updated Salary: ₹45000

Explanation:
1. var salary = 40000; declares a variable.
2. salary = 45000; changes its value.
3. Both statements are valid.
Special behavior of var: Redeclaration
var employee = "Rahul";
var employee = "Priya";

document.write(employee);


Output:
Priya


The same variable can be declared again in the same scope using var. This can accidentally overwrite an existing value.

4. Example 2: let — Variable value can change
Real-time example: A student's marks are updated after re-evaluation.
<!DOCTYPE html>
<html>
<body>
    <h2>let Example</h2>

    <script>
        let studentName = "Amit";
        let marks = 75;

        document.write("Student Name: " + studentName + "<br>");
        document.write("Original Marks: " + marks + "<br>");

        marks = 85;

        document.write("Updated Marks: " + marks);
    </script>
</body>
</html>


Output:
let Example
Student Name: Amit
Original Marks: 75
Updated Marks: 85

Explanation:
- let allows reassignment.
- It does not allow redeclaration in the same scope.
For example, this causes a syntax error:
let marks = 75;
let marks = 85; // SyntaxError


However, this is valid:
let marks = 75;
marks = 85;

document.write(marks);


Output:
85

6. Important concept: Block scope
A block is a section of code enclosed in curly braces { }, such as an if statement.
let and const are block-scoped, whereas var is not.
Try this complete example:
<!DOCTYPE html>
<html>
<body>
    <h2>Block Scope Example</h2>

    <script>
        if (true) {
            var firstName = "Rahul";
            let age = 25;
            const city = "Bangalore";

            document.write("Inside Block:<br>");
            document.write(firstName + "<br>");
            document.write(age + "<br>");
            document.write(city + "<br><br>");
        }

        document.write("Outside Block:<br>");

        document.write("First Name: " + firstName + "<br>");

        // These would cause ReferenceError:
        // document.write(age);
        // document.write(city);
    </script>
</body>
</html>


Output:
Block Scope Example
Inside Block:
Rahul
25
Bangalore

Outside Block:
First Name: Rahul

Why?
- firstName is declared with var, so it is accessible outside the if block within the same function or script scope.
- age and city are declared with let and const, so they are accessible only inside that block.

7. Example: Redeclaration comparison
// var: redeclaration is allowed
var x = 10;
var x = 20;

// let: reassignment is allowed
let y = 10;
y = 20;

// const: reassignment is not allowed
const z = 10;
// z = 20; // TypeError

document.write("x = " + x + "<br>");
document.write("y = " + y + "<br>");
document.write("z = " + z);
