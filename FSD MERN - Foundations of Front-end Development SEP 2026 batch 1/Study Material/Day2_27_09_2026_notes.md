What is HTML?

HTML = HyperText Markup Language

HTML is a markup language used to define the 
structure and content of a web page.

HTML tells the browser:

What is a heading?
What is a paragraph?
Where is an image?
Where is a link?
What is a list?
What is a table?
What is a form?
Which content belongs together?

Simple example

<h1>Employee Management System</h1>

<p>Welcome to the Employee Management System.</p>

<a href="https://www.google.com">Visit Google</a>

The browser interprets these HTML elements and displays them as a web page.

3. <!DOCTYPE html>

<!DOCTYPE html> tells the browser that the document uses HTML5.

<!DOCTYPE html>

It is normally the first line of an HTML document.

Important

It is not an HTML tag in the usual sense.
It is a document type declaration.

4. <html> Tag

The <html> element is the root element of an HTML document.

Everything else normally exists inside <html>.

<!DOCTYPE html>

<html>

    ...

</html>

Example:

<!DOCTYPE html>

<html>

<head>
    <title>My Website</title>
</head>

<body>
    <h1>Welcome</h1>
</body>

</html>
5. <head> Tag

The <head> contains information about the web page that is generally not displayed as normal page content.

Example:

<head>

    <title>Employee Application</title>

</head>

The <head> can contain:

<title>
<meta>
<link>
<style>
<script> references
Other document metadata

For now, the most important one is <title>.

6. <title> Tag

The <title> defines the title of the document.

<title>Employee Management System</title>

It appears in the browser tab.

Complete example:

<!DOCTYPE html>

<html>

<head>

    <title>Employee Management System</title>

</head>

<body>

    <h1>Employee Management System</h1>

</body>

</html>

Browser:

+------------------------------------------------+
| Employee Management System              [-][x] |
+------------------------------------------------+
|                                                |
| Employee Management System                     |
|                                                |
+------------------------------------------------+

Notice that the <title> is shown in the browser tab, while <h1> is shown inside the page.

7. <body> Tag

The <body> contains the content that is displayed on the web page.

<body>

    <h1>Welcome</h1>

    <p>This is my web page.</p>

</body>

Headings

Lists

HTML uses tags to define elements.

Example:

<p>Hello World</p>

Here:

<p>          Opening tag

Hello World  Content

</p>         Closing tag

Together they form an HTML element.

+--------------------------------+
|         HTML Element           |
+--------------------------------+
| <p> Hello World </p>           |
+--------------------------------+
9. Opening and Closing Tags

Most HTML elements have:

<tag>
    content
</tag>

For example:

and:
