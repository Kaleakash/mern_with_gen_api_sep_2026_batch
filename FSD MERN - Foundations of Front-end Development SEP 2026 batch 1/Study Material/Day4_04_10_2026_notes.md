What is CSS?

CSS (Cascading Style Sheets) is a language used to 
style and design HTML web pages.

HTML defines the structure/content of a webpage, 
while CSS defines how that content looks and is positioned.

For example:

<h1>Hello World</h1>
<p>Welcome to my website</p>

Without CSS:

Hello World
Welcome to my website

With CSS:

h1 {
    color: blue;
    font-size: 40px;
}

p {
    color: gray;
    font-size: 20px;
}

The browser renders the content with the specified colors, sizes, spacing, etc.

Simple relationship

HTML
  ↓
Structure / Content
  ↓
CSS
  ↓
Style / Layout / Appearance
  ↓
Browser
  ↓
Web Page

Types of CSS

There are three common ways to apply CSS.

Inline CSS

CSS is written directly inside the HTML element using the style attribute.

<tagName style="property:value;property:value">contents</tagName>

<h1 style="color: blue;">Hello World</h1>

Another example:

<p style="font-size: 20px; color: red;">
    Welcome
</p>
Advantages

Simple
Useful for quick testing
Applies to one particular element

Disadvantages
Difficult to maintain
Repeated styles
Mixes HTML and CSS

3.2 Internal CSS or embedded css 

CSS is written inside the <style> tag, usually in the <head>.

<!DOCTYPE html>
<html>
<head>

    <style>
        h1 {
            color: blue;
        }

        p {
            color: green;
        }
    </style>

</head>

<body>

    <h1>Hello World</h1>

    <p>Welcome to CSS</p>

</body>
</html>





Internal CSS is useful when the CSS is intended for one HTML page.

3.3 External CSS

CSS is stored in a separate .css file.

index.html

<!DOCTYPE html>
<html>
<head>

    <link rel="stylesheet" href="style.css">

</head>

<body>

    <h1>Hello World</h1>

    <p>Welcome to CSS</p>

</body>
</html>

style.css

h1 {
    color: blue;
}

p {
    color: green;
}

External CSS is generally preferred for larger applications because the same CSS file can be reused across multiple HTML pages.

CSS Syntax

The basic CSS syntax is:

selector {
    property: value;
}

Example:

h1 {
    color: blue;
    font-size: 40px;
}

Here:

h1              → Selector
color            → Property
blue             → Value
font-size        → Property
40px             → Value

A complete CSS rule is called a CSS rule set.

What is a CSS Selector?

A CSS selector tells the browser which HTML elements should receive the CSS styles.

* : universal selector 
*{
    color:red;
}

For example:

p {
    color: red;
}

Here:

p → Select all <p> elements

Then:

<p>First paragraph</p>
<p>Second paragraph</p>

Both paragraphs become red.

6. Universal Selector *

The universal selector selects all HTML elements.

Syntax:

* {
    property: value;
}

Example:

* {
    margin: 0;
    padding: 0;
}

This applies to all elements:

<h1>Hello</h1>
<p>Welcome</p>
<div>Content</div>
<button>Click</button>
Common use

A common CSS reset is:

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
7. Element / Type Selector

The element selector selects HTML elements based on their tag name.

Example:

p {
    color: blue;
}

This selects:

<p>Paragraph 1</p>
<p>Paragraph 2</p>
<p>Paragraph 3</p>

All <p> elements receive the style.

Another example:

h1 {
    color: red;
}

button {
    background-color: green;
}
8. Class Selector

The class selector is represented using a . dot.

Syntax:

.className {
    property: value;
}

Example:

<p class="highlight">Java</p>
<p>Spring Boot</p>
<p class="highlight">React</p>

CSS:

.highlight {
    color: red;
    font-weight: bold;
}

Result:

Java          ← red
Spring Boot   ← normal
React         ← red

A class can be reused:

<h1 class="title">Employee Management</h1>

<p class="title">Employee Information</p>

<button class="title">Save</button>
.title {
    color: blue;
}

All three elements receive the style.

9. Global vs Local Class Selector

This distinction is useful when explaining CSS architecture.

Global class

A class can be defined generally and reused throughout the application.

.text-center {
    text-align: center;
}

.text-red {
    color: red;
}

.btn {
    padding: 10px 20px;
}

HTML:

<h1 class="text-center">Employee Management</h1>

<p class="text-center">Employee List</p>

<button class="btn">Save</button>

These classes can be reused across many elements.

Local / Component-specific class

A class can be used for a particular component or section.

<div class="employee-card">
    <h2>Akash</h2>
    <p>Java Trainer</p>
</div>
.employee-card {
    border: 1px solid gray;
    padding: 20px;
}

The intention is that .employee-card represents a particular UI component.

Important

CSS itself does not have a special syntax called "global class" and "local class."

The distinction is mainly about how the class is organized and scoped in an application.

For example, in plain CSS:

.title {
    color: blue;
}

is not technically marked as "global" or "local." Its effective scope depends on where the CSS is loaded and whether the application uses a CSS-scoping mechanism.

10. ID Selector

The ID selector uses #.

Syntax:

#idName {
    property: value;
}

HTML:

<h1 id="main-title">
    Employee Management
</h1>

CSS:

#main-title {
    color: blue;
    font-size: 40px;
}
ID should normally be unique
<h1 id="main-title">Employee Management</h1>

Avoid:

<h1 id="main-title">Employee Management</h1>

<p id="main-title">Employee Information</p>

The same ID should not normally be assigned to multiple elements.

This is an important interview/training concept.

| Feature      | Class                     | ID                            |

| Reuse        | Multiple elements         | Normally one element          |

| Specificity  | Lower                     | Higher                        |

What Flexbox is doing

This:

.cart-item {
    display: flex;
}

changes the layout from something like:

₹55,999

Qty: 1

Remove

to:

┌──────────────────────────────────────────────────────────────┐
│ HP Laptop       ₹55,999       Qty: 1       Remove            │
│ Intel Core i5...                                             │
└──────────────────────────────────────────────────────────────┘
Important Flexbox properties
display: flex;

Makes the element a Flex Container.

flex-direction: row;

Arranges children horizontally.

flex-direction: column;

Arranges children vertically.

justify-content: space-between;

Distributes children along the main axis.

align-items: center;

Aligns children along the cross axis.

gap: 30px;

Creates space between flex items.

flex: 1;

Allows an item to consume available space.

Box Model vs Flexbox — Real-World Difference

Imagine this shopping cart:

             SHOPPING CART
                    │
                    ▼
        ┌─────────────────────┐
        │    Cart Container   │
        │                     │
        │ ┌─────────────────┐ │
        │ │ Laptop   ₹55,999│ │
        │ └─────────────────┘ │
        │                     │
        │ ┌─────────────────┐ │
        │ │ Mouse    ₹1,299  │ │
        │ └─────────────────┘ │
        └─────────────────────┘
Box Model

Controls one element's space:

       margin
          ↓
    ┌─────────────┐
    │   border    │
    │ ┌─────────┐ │
    │ │padding  │ │
    │ │ content │ │
    │ └─────────┘ │
    └─────────────┘
Flexbox

Controls how multiple elements are arranged:

┌───────────────────────────────────────────────┐
│ Product      Price       Quantity      Action │
│   ↓           ↓             ↓            ↓    │
└───────────────────────────────────────────────┘
                 FLEXBOX
Easy way to remember

Box Model = Space of an element

Flexbox = Arrangement of elements

And in real applications, they are normally used together.

For example, in an Amazon-style application:

Shopping Cart
     │
     ├── Flexbox → arrange Product, Price, Quantity, Button
     │
     └── Box Model → control padding, border, margin and size
                     of each cart item

This is a much more realistic example because Box Model handles the individual component's physical space, while Flexbox handles the layout of its internal components.
