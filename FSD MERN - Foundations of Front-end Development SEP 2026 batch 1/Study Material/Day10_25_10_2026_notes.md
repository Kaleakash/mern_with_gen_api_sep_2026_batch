JavaScript Object Creation: 

Literal Style, Function Style, and Class Style
In JavaScript, an object is a collection of properties and methods/functions used to 
represent a real-world entity, 
such as an employee, student, bank account, or product.

There are three common ways to create objects:
1. Object Literal Style
2. Constructor Function Style
3. Class Style
Let's understand each approach with its meaning, syntax, real-world examples, and output.

1. Object Literal Style

Meaning: Object literal is the simplest way to create an object directly using curly braces {}. We define properties and methods inside the object.

Use case: When you need a single object to store related data and behavior.
Example: Employee Object

// Creating an object using object literal

const employee = {
    id: 101,
    name: "Raj",
    department: "IT",
    salary: 60000,

    displayDetails: function () {
        console.log("Employee ID:", this.id);
        console.log("Name:", this.name);
        console.log("Department:", this.department);
        console.log("Salary:", this.salary);
    }
};

// Accessing properties
console.log(employee.name);
console.log(employee.department);

// Calling the method
employee.displayDetails();


Output:
Raj
IT
Employee ID: 101
Name: Raj
Department: IT
Salary: 60000


How it works
- employee is the object reference.
- id, name, department, and salary are properties.
- displayDetails() is a method.
- this refers to the current object on which the method is called.
- The dot (.) operator accesses properties and methods.
Key point: Every time you need a separate employee object, 
you generally define another object literal or use a reusable object-creation approach.

2. Function Style (Constructor Function)    : ES5 Style 
Meaning: A constructor function is a regular JavaScript function used to create and initialize multiple objects with a common structure.

We call it using the new keyword.

Use case: When you need to create many objects with similar properties and methods.
Example: Multiple Employee Objects
// Constructor function

function Employee(id, name, department, salary) {
    this.id = id;
    this.name = name;
    this.department = department;
    this.salary = salary;

    this.displayDetails = function () {
        console.log("Employee ID:", this.id);
        console.log("Name:", this.name);
        console.log("Department:", this.department);
        console.log("Salary:", this.salary);
    };
}

// Creating objects
const emp1 = new Employee(
    101, "Raj", "IT", 60000
);

const emp2 = new Employee(
    102, "Priya", "HR", 50000
);

// Accessing object properties
console.log(emp1.name);
console.log(emp2.name);

// Calling methods
emp1.displayDetails();
emp2.displayDetails();

- function Employee(...) defines the constructor.
- this.id = id assigns the received value to the new object's property.
- new Employee(...) creates a new object and invokes the constructor.

Important: In this example, each object also gets its own displayDetails function. To share the method across objects, you can define it on Employee.prototype.

3. Class Style
Meaning: A JavaScript class provides a structured, modern syntax for creating objects with common properties and methods.

Classes were introduced in ES6 (ECMAScript 2015).


Use case: When building applications with multiple related objects, such as employees, bank accounts, products, or customers.


constructor : 
constructor is a type of special function or method 
which help to create a memory. 
constructor concept support only in class style object creation. 
in JS we need to write a function with name as constructor. 
once we write constructor inside a class it call automatically 
when we create a object. 
Example: Employee Class
// Defining a class
class Employee {
    constructor(id, name, department, salary) {
        this.id = id;
        this.name = name;
        this.department = department;
        this.salary = salary;
    }

    displayDetails() {
        console.log("Employee ID:", this.id);
        console.log("Name:", this.name);
        console.log("Department:", this.department);
        console.log("Salary:", this.salary);
    }
}

// Creating objects
const emp1 = new Employee(
    101, "Raj", "IT", 60000
);

const emp2 = new Employee(
    102, "Priya", "HR", 50000
);

// Calling methods
emp1.displayDetails();
emp2.displayDetails();


Output:
Employee ID: 101
Name: Akash
Department: IT
Salary: 60000
Employee ID: 102
Name: Priya
Department: HR
Salary: 50000


How it works
- class Employee defines the class.
- constructor() initializes each new object.
- this refers to the newly created object during construction.
- new Employee(...) creates an instance of the class.
- displayDetails() is defined on the class prototype, so instances share the method.
Important: A class is not called directly like an ordinary function. Use new Employee(...) to create an instance.

5. Real-World Example: Bank Account
The same concept can be used to represent a bank account.
A. Object Literal

const account = {
    holder: "Akash",
    balance: 10000,

    deposit(amount) {
        this.balance += amount;
    }
};

account.deposit(2000);
console.log(account.balance); // 12000


Good for a single account object.

B. Constructor Function

function BankAccount(holder, balance) {
    this.holder = holder;
    this.balance = balance;

    this.deposit = function (amount) {
        this.balance += amount;
    };
}
const account1 = new BankAccount("Akash", 10000);
const account2 = new BankAccount("John", 12000);
account1.deposit(2000);
account2.deposit(1500);
console.log(account1.balance); // 12000
console.log(account2.balance); // 10500


Good for creating many accounts with a common structure.

React JS we use more function style component creation.

    }
}

const account = new BankAccount("Akash", 10000);

In JavaScript, synchronous and asynchronous programming 
describe how statements and operations are executed.
- Synchronous: Executes statements one after another. 
The next statement waits until the current operation finishes.
- Asynchronous: Allows JavaScript to continue executing other 
code while waiting for an operation to complete.
Let's understand these concepts with meaningful, real-world examples.

1. Synchronous Programming

Meaning: In synchronous programming, each statement executes in sequence. 
The next statement starts after the previous statement finishes.
Example: Employee Registration

console.log("1. Registration started");         fun1()
console.log("2. Validating employee details");  fun2()
console.log("3. Saving employee details");      fun3()
console.log("4. Registration completed");       fun4()


Output:
1. Registration started
2. Validating employee details
3. Saving employee details
4. Registration completed


Explanation:
1. Registration starts.
2. Employee details are validated.
3. Details are saved.
4. Registration completes.

Each statement runs in order.
Example: Synchronous Blocking Operation
console.log("Task 1 started");

// Simulate a blocking operation for 3 seconds
const start = Date.now();

while (Date.now() - start < 3000) {
    // Waiting
}

console.log("Task 1 completed");

console.log("Task 2 started");


Output:
Task 1 started
Task 1 completed
Task 2 started


The second task cannot start until the blocking loop finishes. During those three seconds, JavaScript cannot process other work on that thread.

3. What are setTimeout() and setInterval()?
These are built-in JavaScript timer functions commonly available in browsers and Node.js.
Function	Meaning
setTimeout()	Executes a callback once after a specified delay.
setInterval()	Repeatedly executes a callback at a specified interval.
clearTimeout()	Cancels a pending timeout.
clearInterval()	Stops a repeating interval.

The delay is specified in milliseconds.
- 1 second = 1,000 milliseconds
- 3 seconds = 3,000 milliseconds
- 5 seconds = 5,000 milliseconds
4. setTimeout() — Execute Once After a Delay
Meaning: setTimeout() schedules a function to execute once after the specified delay.

Syntax:
setTimeout(callback, delayInMilliseconds);


Example: Send a Welcome Message
console.log("User logged in");

setTimeout(() => {
    console.log("Welcome! Your profile is ready.");
}, 3000);

console.log("Loading dashboard...");


Output:
User logged in
Loading dashboard...
Welcome! Your profile is ready.


The welcome message appears after approximately three seconds.
Real-world use cases
- Displaying a notification after a delay.
- Hiding a success message after a few seconds.
- Delaying a search request.
- Running a task after a specified waiting period.
Example: Hide a Success Message
console.log("Employee saved successfully!");

setTimeout(() => {
    console.log("Success message hidden");
}, 5000);


Here, the success message is reported as hidden after five seconds. In a web application, you would update the DOM or UI inside the callback to actually hide the message.

5. clearTimeout() — Cancel a Scheduled Timeout
Meaning: clearTimeout() cancels a timeout that has not executed yet.
Example: Cancel an Order Confirmation Message
console.log("Order placed");

const timerId = setTimeout(() => {
    console.log("Order confirmation notification");
}, 5000);

// Cancel the scheduled notification
clearTimeout(timerId);

console.log("Notification cancelled");


Output:
Order placed
Notification cancelled


The confirmation callback does not execute because the timeout is cleared before it fires.

Important: clearTimeout() needs the timer ID returned by setTimeout().
const timerId = setTimeout(() => {
    console.log("Hello");
}, 3000);

clearTimeout(timerId);



6. setInterval() — Execute Repeatedly
Meaning: setInterval() schedules a callback to repeat at a specified interval until it is cancelled.

Syntax:
setInterval(callback, intervalInMilliseconds);


Example: Digital Counter
let count = 1;

const intervalId = setInterval(() => {
    console.log("Counter:", count);
    count++;

    if (count > 5) {
        clearInterval(intervalId);
        console.log("Counter stopped");
    }
}, 1000);


Output:
Counter: 1
Counter: 2
Counter: 3
Counter: 4
Counter: 5
Counter stopped


How the counter works
1. Start the counter at 1.
2. Run the callback approximately every second.
3. Print the current counter and increment it.
4. After printing 5, call clearInterval() to stop future executions.

Key point: Unlike setTimeout(), setInterval() repeats until cancelled or otherwise prevented from continuing.

7. clearInterval() — Stop Repeated Execution
Meaning: clearInterval() stops a repeating timer created by setInterval().
Example: Stop a Timer After Five Seconds
let seconds = 0;

const intervalId = setInterval(() => {
    seconds++;

    console.log("Elapsed:", seconds, "seconds");

    if (seconds === 5) {
        clearInterval(intervalId);
        console.log("Timer stopped");
    }
}, 1000);


Output:
Elapsed: 1 seconds
Elapsed: 2 seconds
Elapsed: 3 seconds
Elapsed: 4 seconds
Elapsed: 5 seconds
Timer stopped


Explanation:
- setInterval() repeats the callback.
- intervalId identifies that interval.
- clearInterval(intervalId) cancels future repetitions.
