A. Array object

array is also known as reference data type. 
it is use to store more than one value of same as well as different types. 
Stores multiple values in an ordered list.
const names = ["Akash", "Priya", "Rahul"];

console.log(names[0]);    // Akash
names.push("Sneha");
console.log(names.length); // 4
console.log(names.includes("Priya")); // true


Common methods: push(), pop(), map(), filter(), find(), includes().


B. String object and string methods
Used to work with text. String literals are primitive strings, 
but JavaScript provides string methods for them.

const message = "  Hello JavaScript  ";
console.log(message.length);
console.log(message.trim());
console.log(message.toUpperCase());
console.log(message.includes("Java"));
console.log(message.slice(2, 7));


Common methods: trim(), toUpperCase(), toLowerCase(), includes(), replace(), split(), slice().

C. Math object

Provides mathematical constants and functions. 
Math is a built-in object and does not need to be instantiated with new.
console.log(Math.sqrt(64));    // 8
console.log(Math.max(10, 25, 5)); // 25
console.log(Math.round(4.6));  // 5
console.log(Math.floor(4.9));  // 4
console.log(Math.ceil(4.1));   // 5
console.log(Math.PI);       // 


Common methods: sqrt(), max(), min(), round(), floor(), ceil(), random().

D. Date object
Used to work with dates and times.

const today = new Date();
console.log(today);
console.log(today.getFullYear());
console.log(today.getMonth()); // 0 = January
console.log(today.getDate());
console.log(today.getHours());
console.log(today.toLocaleDateString());


Common methods: getFullYear(), getMonth(), getDate(), getHours(), toISOString(), toLocaleDateString().
Note: getMonth() returns a zero-based month, from 0 to 11.

BOM – Browser Object Model
The Browser Object Model (BOM) refers to browser-provided objects 
that let JavaScript interact with the browser 
environment beyond the page's HTML content.
The main browser object is window. 
Many browser APIs are accessible through it.
window

location
Current URL and navigation

history
Browser navigation history

navigator
Browser and platform information

screen
Screen dimensions and properties


BOM examples
// Display a message
window.alert("Welcome!");

// Get browser viewport dimensions
console.log(window.innerWidth);
console.log(window.innerHeight);

// Get current URL
console.log(window.location.href);

// Navigate to another page (uncomment to execute)
// window.location.href = "https://example.com";

// Browser history navigation (uncomment to execute)
// window.history.back();

// Browser information
console.log(window.navigator.userAgent);

// Screen dimensions
console.log(window.screen.width);
console.log(window.screen.height);


Other common BOM-related APIs include 
setTimeout(), setInterval(), and browser storage APIs such as localStorage.
Use navigation and history-changing operations carefully because they change the browser's state.
