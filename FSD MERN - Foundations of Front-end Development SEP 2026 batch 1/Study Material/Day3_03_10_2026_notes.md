Understanding href
<a href="https://www.google.com">
    Google
</a>

Here:

<a>                       → Anchor element

href                      → Attribute

https://www.google.com    → URL

Google                    → Text displayed to user
13. Opening Link in New Tab

You can use:

target="_blank"

Example:

<a
    href="https://www.google.com"
    target="_blank">

    Open Google

</a>

The link will normally open in a new browser tab.

14. Image — <img>

The <img> element displays an image.

Basic syntax:

<img src="image.jpg" alt="Description">

Important attributes:

src
alt
src

Specifies the image location.

src="employee.jpg"
alt

Provides alternative text describing the image.

alt="Employee photo"
15. Image Working Example

Suppose your folder contains:

html-training/
    image.html
    employee.jpg

image.html:

<!DOCTYPE html>

<html>

<head>

    <title>Image Example</title>

</head>

    <h1>Employee Profile</h1>

    <img
        src="employee.jpg"
        alt="Employee Photo">

        Employee: Akash
    </p>

When opened in the browser, the image is displayed.

16. Image Using an Internet URL

You can also use an image URL.

<img
    src="https://example.com/employee.jpg"
    alt="Employee Photo">

For training, however, using a local image is often easier because it doesn't depend on an external website.
