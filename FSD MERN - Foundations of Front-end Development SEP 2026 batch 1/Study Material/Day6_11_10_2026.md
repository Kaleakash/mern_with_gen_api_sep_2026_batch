What is an Operator in JavaScript?

Definition: An operator is a symbol 
or keyword used to perform an operation on values or variables.
Real-time example: In an Employee Management System, 
we use operators to calculate salary, check age eligibility, 
compare employee performance, and validate login conditions.
let basicSalary = 40000;
let bonus = 5000;

let totalSalary = basicSalary + bonus;

document.write("Basic Salary: ₹" + basicSalary + "<br>");
document.write("Bonus: ₹" + bonus + "<br>");
document.write("Total Salary: ₹" + totalSalary);


Output:
Basic Salary: ₹40000
Bonus: ₹5000
Total Salary: ₹45000

Here, + is an operator that adds two numbers.
2. Types of JavaScript Operators
JavaScript operators can be grouped into the following categories.

1. Arithmetic operators
Perform mathematical calculations.
+, -, *, /, %, **, ++, --




2. Assignment operators
Assign or update variable values.
=, +=, -=, *=, /=, %=, **=




3. Comparison operators
Compare two values and return a Boolean.
==, ===, !=, !==, >, <, >=, <=




4. Logical operators
Combine or reverse conditions.
&&, ||, !




5. Other important operators
Handle conditions, types, properties, and values.
Ternary ? :, typeof, ??, ?., in, instanceof

What is a Conditional Statement?

Definition: A conditional statement is used to 
execute different blocks of code depending on 
whether a condition is true or false.

Real-time use cases:
- Check whether a student passed or failed.
- Check whether an employee is eligible for a bonus.
- Validate login credentials.
- Calculate grades based on marks.
- Display a different message depending on the day of the week.
For example, a student passes if their marks are at least 40.

let marks = 35;

if (marks >= 40) {
    document.write("Student Passed");
}
document.write("Done")

Output in the browser:
Student Passed

if (marks >= 40) {
    document.write("Student Passed");
}else {
    document.write("Student Failed");
}
document.write("Done")

How it works:
1. let marks = 75 stores the student's marks.
2. marks >= 40 checks whether the marks are at least 40.
3. Because the condition is true, the code inside the if block executes.

5. if...else if...else Statement
Definition: This statement checks multiple conditions one after another. The first true condition's block executes. If none is true, the final else block executes.
Syntax:
if (condition1) {
    // First condition
} else if (condition2) {
    // Second condition
} else if (condition3) {
    // Third condition
} else {
    // No condition matched
}


Meaningful example: Student grading system
Marks	Grade
90–100	A
75–89	B
60–74	C
40–59	D
Below 40	F

<!DOCTYPE html>
<html>
<body>
    <h2>Student Grading System</h2>

    <script>
        let studentName = "Amit";
        let marks = 82;
        let grade;

        if (marks < 0 || marks > 100) {
            grade = "Invalid Marks";
        } else if (marks >= 90) {
            grade = "A";
        } else if (marks >= 75) {
            grade = "B";
        } else if (marks >= 60) {
            grade = "C";
        } else if (marks >= 40) {
            grade = "D";
        } else {
            grade = "F";
        }

        document.write("Student: " + studentName + "<br>");
        document.write("Marks: " + marks + "<br>");
        document.write("Grade: " + grade);
    </script>
</body>
</html>


Output:
Student Grading System
Student: Amit
Marks: 82
Grade: B

Important: Conditions must be arranged carefully. The program checks marks >= 90 first, then marks >= 75, and so on. Once one condition matches, the remaining branches are skipped.
6. Nested if Statement
Definition: A nested if statement is an if statement placed inside another if statement. It is useful when a second condition should be checked only after the first condition is satisfied.
Meaningful example: Employee portal login
An employee must first enter the correct username. Then the password is checked.

<!DOCTYPE html>
<html>
<body>
    <h2>Employee Login</h2>

    <script>
        let username = "rahul";
        let password = "java123";

        if (username === "rahul" ) {
            document.write("Username is correct<br>");

            if (password === "java123") {
                document.write("Login Successful");
            } else {
                document.write("Incorrect Password");
            }

        } else {
            document.write("Incorrect Username");
        }
    </script>
</body>
</html>


Output:
Employee Login
Username is correct
Login Successful

How it works:
1. The outer if checks the username.
2. If the username is correct, the inner if checks the password.
3. If both are correct, the login succeeds.
4. If the username is incorrect, the password check is skipped.
Training note: This example demonstrates conditional logic only. Real applications must authenticate credentials securely on the server and must not store plaintext passwords in frontend JavaScript.

7. switch Statement
Definition: The switch statement selects 
one block of code from several possible cases, 
based on the value of an expression.
It is useful when one variable can have several known values, 
such as a menu choice, day of the week, or order status.

Syntax:

switch (expression) {
    case value1:
        // Code for value1
        break;

    case value2:
        // Code for value2
        break;

    default:
        // Code when no case matches
}


- switch evaluates the expression.
- case specifies a possible matching value.
- break exits the switch block.
- default executes when no case matches.
Meaningful example: Employee department selection

<!DOCTYPE html>
<html>
<body>
    <h2>Employee Department Information</h2>

    <script>
        let departmentCode = 4;
        document.write("Department Code: " +
            departmentCode + "<br>");
        switch (departmentCode) {
            case 1:
                document.write("Department: Human Resources");
                break;
            case 2:
                document.write("Department: Java Development");
                break;
            case 3:
                document.write("Department: Testing");
                break;
            case 4:
                document.write("Department: Finance");
                break;
            default:
                document.write("Invalid Department Code");
        }
    </script>
</body>
</html>


Output:
Employee Department Information
Department Code: 2
Department: Java Development

If you change departmentCode = 2 to departmentCode = 3, the output will be Department: Testing.
Why is break important?
Consider this example without break:
let day = 2;

switch (day) {
    case 1:
        document.write("Monday<br>");

    case 2:
        document.write("Tuesday<br>");

    case 3:
        document.write("Wednesday<br>");
}


Output:
Tuesday
Wednesday


Without break, execution continues into subsequent cases. This is called fall-through. Use break when you want to stop after the matching case.
8. switch vs if...else if
| Feature | if...else if | switch |
|---|---|---|
| Best suited for | Ranges and complex conditions | Matching specific values |
| Conditions | Supports >, <, &&, ||, and more | Matches case values using strict equality |
| Example | marks >= 75 | departmentCode === 2 |
| Default path | else | default |
| Exit behavior | Continues after the selected block | Usually uses break to exit |
Rule of thumb:
- Use if...else if for grading, salary eligibility, age checks, and numeric ranges.
- Use switch for menu options, department codes, fixed statuses, and days of the week.

What is Looping in JavaScript?
Definition: Looping is a programming technique used to execute a 
block of code repeatedly while a condition is satisfied or for a specified number of iterations.

Why do we need loops?
Suppose you want to display the names of 100 employees. Without loops, you might write 100 separate statements. With a loop, you can execute the same logic repeatedly using a few lines of code.
Real-time use cases:
- Display student marks one by one.
- Print employee IDs.
- Calculate the total of multiple product prices.
- Process items in a shopping cart.
- Repeat an operation until a condition is met.
JavaScript provides three commonly used loops:

1. while loop
Checks the condition before executing the loop body.




2. do...while loop
Executes the loop body at least once, then checks the condition.




3. for loop
Combines initialization, condition, and update in one statement.



2. while Loop
Definition: A while loop repeatedly executes a block of code as long as its condition is true.
Syntax

while (condition) {
    // Statements to execute
    // Update the condition variable
}


Example 1: Display employee IDs
Suppose a company has five employees with IDs from 101 to 105.

<!DOCTYPE html>
<html>
<head>
    <title>While Loop Example</title>
</head>
<body>
    <h2>Employee ID List</h2>

    <script>
        let employeeId = 101;

        while (employeeId <= 105) {
            document.write("Employee ID: " + employeeId + "<br>");

            employeeId++;
        }
    </script>
</body>
</html>



Output:
Employee ID List
Employee ID: 101
Employee ID: 102
Employee ID: 103
Employee ID: 104
Employee ID: 105

Step-by-step execution
Iteration	employeeId	Condition	Action
1	101	101 <= 105 → true	Display 101
2	102	102 <= 105 → true	Display 102
3	103	103 <= 105 → true	Display 103
4	104	104 <= 105 → true	Display 104
5	105	105 <= 105 → true	Display 105
6	106	106 <= 105 → false	Stop
Important: employeeId++ increments the variable. Without it, the condition would remain true and the loop could run indefinitely.
3. do...while Loop
Definition: A do...while loop executes its code block first and checks the condition afterward. Therefore, the loop body always executes at least once, even when the condition is initially false.
Syntax
do {
    // Statements to execute
} while (condition);


Notice the semicolon (;) after the while condition.
Example 2: Display training session numbers
Suppose a trainer wants to display session numbers starting from 1 until session 5.

<!DOCTYPE html>
<html>
<head>
    <title>Do While Loop Example</title>
</head>
<body>
    <h2>Training Session Schedule</h2>

    <script>
        let session = 1;

        do {
            document.write("Training Session: " + session + "<br>");

            session++;
        } while (session <= 5);
    </script>
</body>
</html>



Output:
Training Session Schedule
Training Session: 1
Training Session: 2
Training Session: 3
Training Session: 4
Training Session: 5

Important difference: while vs do...while
Consider this example, where the condition is false from the beginning.
let count = 10;

while (count < 5) {
    document.write("While loop executed<br>");
}

do {
    document.write("Do while loop executed<br>");
} while (count < 5);


Output:
Do while loop executed


Why?
- while checks 10 < 5 first. It is false, so the body never executes.
- do...while executes its body first. It displays the message once, then checks the false condition and stops.
Real-time use case: Displaying a menu at least once
let choice = 0;

do {
    document.write("1. View Employees<br>");
    document.write("2. Add Employee<br>");
    document.write("0. Exit<br>");
    document.write("Menu displayed<br>");
} while (choice !== 0);


Output:
1. View Employees
2. Add Employee
0. Exit
Menu displayed


This illustrates the execute-first behavior. In a real interactive application, the user's menu choice would be collected and updated inside the loop to control repetition.
4. for Loop
Definition: A for loop repeats a block of code while a condition remains true. It is especially useful when the number of iterations is known or controlled by a counter.
Syntax
for (initialization; condition; update) {
    // Statements to execute
}


The three parts are:
- Initialization: Runs once before the loop starts.
- Condition: Checked before each iteration.
- Update: Runs after each iteration.
Example 3: Display student marks
Suppose five students have marks stored in an array, and we want to display each student's marks.

<!DOCTYPE html>
<html>
<head>
    <title>For Loop Example</title>
</head>
<body>
    <h2>Student Marks Report</h2>

    <script>
        let marks = [85, 72, 91, 68, 78];

        for (let i = 0; i < marks.length; i++) {
            document.write(
                "Student " + (i + 1) +
                " Marks: " + marks[i] + "<br>"
            );
        }
    </script>
</body>
</html>



Output:
Student Marks Report
Student 1 Marks: 85
Student 2 Marks: 72
Student 3 Marks: 91
Student 4 Marks: 68
Student 5 Marks: 78

Step-by-step explanation
1. let i = 0 initializes the counter.
2. i < marks.length checks whether another mark exists.
3. marks[i] retrieves the mark at the current array index.
4. i++ moves to the next index.
5. When i reaches 5, the condition becomes false and the loop stops.
Remember that array indexes start from 0, so the five marks are at indexes 0 through 4.

6. Difference between while, do...while, and for
Feature	while	do...while	for
Condition checked	Before execution	After execution	Before each iteration
Minimum executions	Zero	One	Zero
Initialization	Usually before loop	Usually before loop	In loop declaration
Update	Usually inside body	Usually inside body	Usually in update section
Best use case	Repeat until a condition changes	Execute at least once	Counter-based repetition



What is a function in JavaScript?
A function in JavaScript is a reusable block of code designed to perform a particular task. We write the code once and execute it whenever required by calling the function.
Real-time example: In an employee management application, we can create functions to calculate salary, display employee details, and calculate bonuses.
Example 1: Simple function
<!DOCTYPE html>
<html>
<head>
    <title>JavaScript Function</title>
</head>
<body>
    <h2>Employee Management System</h2>

    <script>
        // Function definition
        function displayMessage() {
            document.write("Welcome to Employee Management System!");
        }

        // Function call
        displayMessage();
    </script>
</body>
</html>


Output:
Employee Management System
Welcome to Employee Management System!
Explanation:
- function — keyword used to declare a function.
- displayMessage — function name.
- () — holds parameters, if required.
- {} — contains the function body.
- displayMessage() — calls and executes the function.
2. Types of functions in JavaScript
The following are important function types to learn.
Type	Description
1. Function declaration	A function declared using the function keyword
2. Function with parameters	Accepts input values
3. Function with return value	Returns a result to the caller
4. Function expression	Stores a function in a variable
5. Anonymous function	A function without a name
6. Arrow function	Uses the => syntax
7. Callback function	A function passed to another function
8. Immediately Invoked Function Expression (IIFE)	Executes immediately after definition
9. Recursive function	Calls itself to solve a problem
Let's understand these step by step.
3. Function without parameters and return value
This function performs a task but does not accept inputs or return a result.
function greet() {
    document.write("Good morning!<br>");
}

greet();
greet();
greet();


Output:
Good morning!
Good morning!
Good morning!


Use case: Displaying a welcome message, showing a menu, or displaying a heading.
4. Function with parameters
Parameters allow a function to accept input values.
Example: Calculate employee salary
<script>
    function calculateSalary(basicSalary, bonus) {
        let totalSalary = basicSalary + bonus;

        document.write("Basic Salary: ₹" + basicSalary + "<br>");
        document.write("Bonus: ₹" + bonus + "<br>");
        document.write("Total Salary: ₹" + totalSalary + "<br>");
    }

    calculateSalary(30000, 5000);
    document.write("<hr>");
    calculateSalary(40000, 8000);
</script>


Output:
Basic Salary: ₹30000
Bonus: ₹5000
Total Salary: ₹35000

Basic Salary: ₹40000
Bonus: ₹8000
Total Salary: ₹48000

Explanation:
- basicSalary and bonus are parameters.
- 30000 and 5000 are arguments in the first function call.
- The function uses these values to calculate the total salary.
5. Function with a return value
The return statement sends a result back to the code that called the function.
<script>
    function calculateTotal(price, quantity) {
        let total = price * quantity;
        return total;
    }

    let bill = calculateTotal(500, 4);

    document.write("Total Bill: ₹" + bill);
</script>


Output:
Total Bill: ₹2000


How it works:
1. The function receives 500 and 4.
2. It calculates 500 * 4.
3. return total sends 2000 back.
4. The result is stored in the bill variable.
Important: return and document.write() are different. return gives a value back to the caller; document.write() displays content on the page.
6. Function expression
A function expression stores a function in a variable.
const calculateArea = function(length, width) {
    return length * width;
};

let area = calculateArea(10, 5);

document.write("Area of Rectangle: " + area);


Output:
Area of Rectangle: 50


Here, calculateArea is a variable holding a function. Because it is declared with const, the variable cannot be reassigned.
7. Anonymous function
An anonymous function is a function without its own name. It is commonly used as a callback or assigned to a variable.
const showMessage = function() {
    document.write("Your registration is successful!");
};

showMessage();


Output:
Your registration is successful!


The function itself has no name after the function keyword, but the variable showMessage provides a way to call it.
8. Arrow function
An arrow function provides a shorter syntax for writing functions.
Traditional function
function add(a, b) {
    return a + b;
}

document.write(add(10, 20));


Equivalent arrow function
const add = (a, b) => {
    return a + b;
};

document.write(add(10, 20));


Output:
30


Shorter arrow function
When the function contains only a single return expression, you can omit the braces and return keyword.
const add = (a, b) => a + b;

document.write("Addition: " + add(10, 20));


Output:
Addition: 30


Arrow functions are widely used in modern JavaScript, React, array methods, and asynchronous programming.
9. Callback function
A callback is a function passed as an argument to another function. The receiving function can execute it when needed.
Example: Employee notification
function processEmployee(name, callback) {
    document.write("Processing employee: " + name + "<br>");

    callback();
}

function sendNotification() {
    document.write("Employee registration completed!");
}

processEmployee("Rahul", sendNotification);


Output:
Processing employee: Rahul
Employee registration completed!


Notice that we pass sendNotification without parentheses. The receiving function calls it using callback().
Callback using an arrow function
function calculateBonus(salary, callback) {
    let bonus = salary * 0.10;
    callback(bonus);
}

calculateBonus(40000, function(bonus) {
    document.write("Employee Bonus: ₹" + bonus);
});


Output:
Employee Bonus: ₹4000


10. Immediately Invoked Function Expression (IIFE)
An IIFE is a function that executes immediately after it is defined.
(function() {
    document.write("Application initialized successfully!");
})();


Output:
Application initialized successfully!


Use case: Running initialization code immediately without needing to call the function separately.
11. Recursive function
A recursive function calls itself until a stopping condition is reached.
Example: Calculate factorial
The factorial of 5 is:
\[
5! = 5 \times 4 \times 3 \times 2 \times 1 = 120
\]

function factorial(n) {
    if (n <= 1) {
        return 1;
    }

    return n * factorial(n - 1);
}

document.write("Factorial of 5: " + factorial(5));


Output:
Factorial of 5: 120


The condition n <= 1 is the base case. Without a suitable stopping condition, recursion may continue until an error occurs.

12. Default parameters
Default parameters provide a value when an argument is omitted or explicitly passed as undefined.
function greetUser(name = "Guest") {
    document.write("Welcome, " + name + "!<br>");
}

greetUser("Rahul");
greetUser();


Output:
Welcome, Rahul!
Welcome, Guest!


13. Local and global variables in functions
let company = "ABC Technologies"; // Global variable

function displayEmployee() {
    let employeeName = "Priya"; // Local variable

    document.write("Company: " + company + "<br>");
    document.write("Employee: " + employeeName);
}

displayEmployee();


Output:
Company: ABC Technologies
Employee: Priya


- Global variable: Declared outside the function and accessible within its scope.
- Local variable: Declared inside the function and generally accessible only within that function.

15. Function declaration vs function expression vs arrow function
Feature	Function declaration	Function expression	Arrow function
Syntax	function add() {}	const add = function() {}	const add = () => {}
Name	Usually named	Named or anonymous	Often stored in a variable
Hoisting	Can be called before declaration	Variable rules apply	Variable rules apply

Important: Function declarations are hoisted with their function body. Function expressions and arrow functions assigned to let or const cannot be called before the variable initialization.
