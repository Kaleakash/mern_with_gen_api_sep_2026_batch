
What is a Promise in JavaScript?
A Promise is a JavaScript object that represents the eventual 
success or failure of an asynchronous operation.

Promise is a pre defined JS object which is use to handle 
asynchronous event of data of any types. 


For example, imagine an application requesting employee details from a server. 
The server may return the data after some time, or the request may fail.

A Promise helps us handle both situations.

Real-world examples:
- Fetching employee details from an API.
- Processing an online payment.
- Reading data from a database.
- Uploading a file.
- Checking login credentials.

2. Three States of a Promise
A Promise has three possible states.
1. Pending

The operation is still in progress.
2. Fulfilled

The operation succeeded. The Promise was resolved successfully.

3. Rejected

The operation failed.




A settled Promise is either fulfilled or rejected. Its state does not change again.
3. Why Do We Use Promises?
Consider this example without a Promise:
console.log("Request started");

setTimeout(() => {
    console.log("Employee data received");
}, 2000);

console.log("Continue application");


Output:
Request started
Continue application
Employee data received


The code works, but if another operation depends on the employee data, managing multiple callbacks can become difficult.

Promises provide a structured way to handle the result or error using .then(), .catch(), and .finally().
4. Creating a Custom Promise
We can create our own Promise using the new Promise() constructor.
Syntax
const promise = new Promise((resolve, reject) => {
    // Perform an operation

    if (success) {
        resolve(result);
    } else {
        reject(error);
    }
});


- resolve() — indicates successful completion.
- reject() — indicates failure.
- .then() — handles successful fulfillment.
- .catch() — handles rejection.
- .finally() — runs after settlement, whether fulfilled or rejected.
5. Simple Example: Check a Student's Exam Result

Let's create a custom Promise that checks whether a student has passed an exam.
const examResult = new Promise((resolve, reject) => {
    const marks = 75;

    if (marks >= 40) {
        resolve("Congratulations! You passed.");
    } else {
        reject("Sorry! You failed.");
    }
});

examResult
    .then((message) => {
        console.log(message);
    })
    .catch((error) => {
        console.log(error);
    });


Output:
Congratulations! You passed.


How does it work?
1. new Promise() creates a Promise.
2. The executor function runs immediately.
3. The program checks whether marks are at least 40.
4. Since marks are 75, resolve() is called.
5. .then() receives the success message.
6. .catch() does not run because the Promise was not rejected.
Try changing marks to 25. The Promise will be rejected, and .catch() will print Sorry! You failed.
6. Custom Promise with setTimeout()
Now let's create a more realistic asynchronous example.

Scenario: An application takes two seconds to retrieve employee details.
function getEmployee() {
    return new Promise((resolve, reject) => {
        console.log("Fetching employee details...");

        setTimeout(() => {
            const employee = {
                id: 101,
                name: "Akash",
                department: "IT"
            };

            resolve(employee);
        }, 2000);
    });
}

getEmployee()
    .then((employee) => {
        console.log("Employee ID:", employee.id);
        console.log("Name:", employee.name);
        console.log("Department:", employee.department);
    })
    .catch((error) => {
        console.log("Error:", error);
    });

console.log("Application continues running...");


Output:
Fetching employee details...
Application continues running...
Employee ID: 101
Name: Akash
Department: IT


The employee details appear after approximately two seconds.

Important: resolve(employee) passes the employee object to the next .then() callback. This is how data moves through a Promise chain.
7. Custom Promise with Success and Failure
Let's simulate a bank account balance check.
function checkBalance(balance, amount) {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            if (balance >= amount) {
                resolve("Transaction successful");
            } else {
                reject("Insufficient balance");
            }
        }, 1000);
    });
}

checkBalance(5000, 2000)
    .then((message) => {
        console.log(message);
    })
    .catch((error) => {
        console.log(error);
    })
    .finally(() => {
        console.log("Transaction process completed");
    });


Output:
Transaction successful
Transaction process completed


If you change the call to checkBalance(5000, 7000), the output becomes:
Insufficient balance
Transaction process completed


Here, finally() executes in either case.

This is only a learning simulation; a real payment system must validate balances and perform transactions securely on the server.

JavaScript fetch() Function — Complete Explanation with Examples
1. What is the fetch() function?
The JavaScript fetch() function is a built-in Web API used to send HTTP requests and communicate with servers or REST APIs.

For example, when you open an employee management application, you may need to retrieve employee details from a backend server. You can use fetch() to request that data.

Common use cases:
- Retrieve employee or student details.
- Submit login credentials to a server.
- Add a new employee.
- Update employee information.
- Delete an employee record.
- Integrate frontend applications with REST APIs.
2. How does fetch() work?
Frontend — JavaScript

Calls fetch()

HTTP Request

GET, POST, PUT, DELETE

Backend REST API

Spring Boot, FastAPI, Node.js, etc.

Response

HTTP status and response data


fetch() returns a Promise. When the server responds, that Promise fulfills with a Response object, or rejects if the request fails at the network level or another request-level error occurs.

The response body, such as JSON, is usually read separately using response.json(), which also returns a Promise.
3. Basic syntax
fetch(url, options)
    .then(response => {
        // Process the HTTP response
    })
    .then(data => {
        // Use the response data
    })
    .catch(error => {
        // Handle request or processing errors
    });


- url: The API endpoint.
- options: Optional settings for the HTTP method, headers, and request body.
- .then(): Handles the next successful step.
- .catch(): Handles a rejected Promise.
4. Example 1: Fetch Employee Data Using GET
We will use the free testing API JSONPlaceholder to retrieve sample data.

    .then(response => response.json())

Step-by-step execution:
1. fetch() sends a GET request to the API.
2. The server returns an HTTP response.
3. response.json() reads and parses the response body.
4. The next .then() receives the parsed employee object.
5. .catch() handles rejected Promises.
5. Important: Check HTTP Errors
One important detail: fetch() does not automatically reject its Promise for HTTP errors such as 404 Not Found or 500 Internal Server Error. Check response.ok to detect unsuccessful HTTP status codes.

fetch("https://jsonplaceholder.typicode.com/users/9999")
    .then(response => {
        if (!response.ok) {
            throw new Error("HTTP Error: " + response.status);
        }

        return response.json();
    })
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.log("Request failed:", error.message);

6. Example 2: Fetch Using async/await
The same request can be written with async and await. This style is often easier to read.
async function getEmployee() {
    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users/1"
        );

        if (!response.ok) {
            throw new Error("HTTP Error: " + response.status);
        }

        const employee = await response.json();

        console.log("ID:", employee.id);
        console.log("Name:", employee.name);
        console.log("Email:", employee.email);
    } catch (error) {
        console.log("Error:", error.message);
    }
}

getEmployee();


Here, await waits for each Promise inside the async function, without blocking the JavaScript thread.

Tailwind and Bootstrap 

Tailwind CSS and Bootstrap are two popular CSS frameworks used to develop responsive and attractive web applications.

Both frameworks help frontend developers build user interfaces faster without writing all CSS styles from scratch.

We will cover these topics step by step, with practical examples suitable for React, Angular, or standalone HTML projects.
1. Introduction to CSS Frameworks
Before understanding Tailwind and Bootstrap, let's understand the problem.

Suppose you want to create a button.

Using normal CSS:
<button class="my-button">Login</button>


.my-button {
    background-color: blue;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 5px;
}


You need to write CSS separately.

CSS frameworks provide predefined utility classes or components to simplify this process.
