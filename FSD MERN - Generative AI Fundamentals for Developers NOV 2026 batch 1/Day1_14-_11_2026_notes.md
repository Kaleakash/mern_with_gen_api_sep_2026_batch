What is Artificial Intelligence (AI)?
Artificial Intelligence (AI) is a branch 
of computer science that focuses on creating machines 
and software that can perform tasks that normally require 
human intelligence.

These tasks include:
- Learning from information.
- Understanding language.
- Recognizing images and objects.
- Solving problems.
- Making predictions.
- Supporting decision-making.
Simple example:

Imagine you receive an email:

"Congratulations! You have won a ₹50,000 prize. 
Click here to claim your reward."

An email application can use AI techniques to 
identify suspicious messages and classify them as spam.

Other examples:
- Google Maps suggesting the fastest route.
- YouTube recommending videos.
- A banking application detecting unusual transactions.
- A mobile phone recognizing your face.

Types of Artificial Intelligence

AI can be explained at a beginner level using three broad categories.

Narrow AI (Weak AI)

Narrow AI is designed to perform a specific task or a 
limited set of tasks.

Examples:
- Voice assistants.
- Recommendation systems.
- Face recognition.
- Spam detection.
- Chatbots designed for customer support.

Real-world example:

A recommendation system on Netflix suggests 
movies based on your viewing history. 
It is designed for recommendations, 
not for independently performing every type of human task.

2.2 General AI (AGI)
Artificial General Intelligence refers 
to a hypothetical type of AI that could understand, 
learn and perform a wide range of intellectual tasks at a 
human-like level.

It is a research concept, 
not a capability that current mainstream AI systems have demonstrated.

2.3 Super AI
Super AI is a hypothetical concept referring to 
AI that would exceed human intellectual capabilities across many areas.

It is a theoretical concept, not an existing technology.

Artificial Intelligence (AI)

3.2 Machine Learning (ML)
Machine Learning is a subset of AI in which computers 
learn patterns from data and use those patterns to make 
predictions or decisions, rather than relying only on

3.3 Deep Learning (DL)
Deep Learning is a subset of Machine Learning that uses 
artificial neural networks with multiple layers to learn 
complex patterns from large amounts of data.

Example:

A face recognition system can learn visual patterns such as:
- Shape of the face.
- Distance between the eyes.
- Nose and mouth features.
- Other visual characteristics.
Deep learning is widely used in image recognition, 
speech recognition and language processing.

3.4 Generative AI (GenAI)
Generative AI is a category of AI that can 
generate new content based on patterns learned 
from its training data and the input provided by users.

It can generate:
- Text.
- Images.
- Computer programs.
- Audio.
- Video.
- Summaries and reports.

Examples:
- ChatGPT generates text responses.
- Image-generation tools create images from text descriptions.
- Coding assistants generate program code.
- AI audio tools generate speech or music.

3.1 Understand the three words: Large, Language and Model

1. Large

Refers to the scale and complexity of the model, 
including the number of learned parameters and the computational resources required.

2. Language

Refers to the model's ability to process and generate human language.

3. Model

A mathematical system whose parameters are learned during training to capture patterns in data.

3.2 What is a parameter?

A parameter is a numerical value learned by a model during training.

These values help the model identify patterns and generate outputs.

Beginner-friendly example:

Imagine a student learning English.

The student studies thousands of sentences and learns:
- A,B,C,
- a,b,c,
- Grammar patterns.
- Word relationships.
- Sentence structure.
- Common expressions.
An LLM also learns patterns from training data, but it does so through mathematical computations and learned parameters.

The parameters are not simply a dictionary of stored sentences.

3.3 What is a token?
A token is a unit of text that a language model processes.

A token may represent:
- A complete word.
- Part of a word.
- Punctuation.
- A space or other text element, depending on the tokenizer.
Example:

Sentence:
I love learning Python.


The model's tokenizer may split this sentence into several tokens. The exact split depends on the model's tokenizer.

Why are tokens important?

Tokens are important because:
- Models process text as tokens.
- Input and output usage can be measured in tokens.
- Context limits are generally measured in tokens.
- Token usage may affect API costs.

3.4 What is a context window?
A context window is the amount of information a model can consider in a
 single interaction or processing request.

It can include:
- User instructions.
- Previous conversation messages.
- Uploaded document content.
- Other information supplied to the model.
Example:

Suppose you upload a long document and ask:

"Summarize Chapter 5."

The model needs access to the relevant chapter content to produce a useful summary.

If the required information exceeds the model's available context or is not supplied properly, 
the model may not be able to process all of it in one request.


3.5 How does an LLM generate a response?

Explain the process step by step:

1. User enters a prompt.
2. The text is converted into tokens.
3. The model processes the token sequence.
4. The model calculates possible next tokens.
5. A next token is selected according to the model's generation settings.
6. This process repeats to generate the response.
7. The generated tokens are converted into readable text.
Example:

Prompt:
The capital of India is


The model estimates likely next tokens based on the context and learned patterns.

A likely completion is:
New Delhi.


Important concept: LLMs do not simply retrieve a fixed answer for every question. They generate responses based on learned patterns and the current context. Their answers can still contain mistakes.
